# AI-Based Chest X-ray Disease Detection

A deep learning web application for detecting:

- COVID-19
- Pneumonia
- Tuberculosis
- Normal

## Models Used

- EfficientNet-B0
- DenseNet121
- ResNet50

## Ensemble Method

Weighted Soft Voting

## Framework

- PyTorch
- Streamlit
- timm

## Run Locally

```bash
pip install -r requirements.txt
streamlit run app.py
